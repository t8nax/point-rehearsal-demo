# Точка Отсчёта — демо онлайн-бронирования

Клиентский сайт и панель администратора репетиционной базы. React, TypeScript и Vite.

[Открыть демо](https://point-rehearsal-dark-boris.t8naxx.chatgpt.site/) · [Панель администратора](https://point-rehearsal-dark-boris.t8naxx.chatgpt.site/admin)

## Запуск

Нужен Node.js 22.12+.

```sh
cd repo-seed
npm ci
npm run dev
```

## Проверка и сборка

```sh
cd repo-seed
npm test
npm run build
```

## Возможности

- Клиентский сайт: выбор зала и времени, фотографии, оборудование, форма записи с имитацией входа через Telegram.
- Расписание `/admin`: ручная запись на год вперёд, учёт выданного оборудования, завершение и оплата, отмена и неявка.
- Каталог `/admin/equipment`: категории, поиск, цены, бесплатное количество, наличие и видимость на клиентском сайте.

Исходники находятся в `repo-seed/src`, исходные данные — в `repo-seed/data/base.json`, фотографии — в `repo-seed/public/photos`.

Это демонстрационное приложение без сервера. Данные сохраняются в браузере и синхронизируются между его вкладками. Реальные брони, платежи и сообщения не создаются; панель администратора не защищена авторизацией.

## Размещение

Для Vercel: Root Directory `repo-seed`, Build Command `npm run build`, Output Directory `dist`. Файл `vercel.json` обеспечивает переходы по маршрутам приложения.

Локальный тест авторизации Telegram, технические копии Sites, сборки и служебные настройки не входят в репозиторий.
