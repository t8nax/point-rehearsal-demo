# Точка Отсчёта — демо онлайн-записи

React + TypeScript + Vite. Клиентский сайт `/` и админка `/admin` в одном приложении. Настоящие брони, платежи и сообщения не создаются.

## Запуск

Нужен Node.js 22.12+.

```powershell
cd D:\Startup\point-demo-package\repo-seed
npm ci
npm run dev
```

Обычно сайт доступен на http://127.0.0.1:5173, админка — на http://127.0.0.1:5173/admin.

```powershell
npm test
npm run build
npm run preview
```

## Текущий этап админки — расписание

Оформление основано на выбранном владельцем проекта HTML-концепте: графитовая тема, Inter, лаймовый акцент, залы по столбцам, время по строкам. Содержание адаптировано к реальным данным семи залов.

- Вчера / сегодня / завтра, стрелки и собственный календарь с ручным вводом ДД.ММ.ГГГГ. Один компонент используется в расписании и ручной записи. Несуществующие и недоступные даты отклоняются; Escape закрывает календарь, сохраняя форму. Просмотр доступен от 14 дней назад на год вперёд; новая запись — только в доступное будущее время.
- Семь залов и четыре временных интервала. В заголовках только названия залов; стоимость есть в карточке брони и форме записи.
- Выбор отдельного зала; на узком экране полная сетка прокручивается внутри своей области, столбец времени остаётся виден.
- По нажатию на бронь открывается боковая панель: группа, зал, дата, время, контакт, источник и стоимость. Статус брони не выдаётся за статус оплаты.
- По нажатию на свободный слот или «Новая бронь» можно вручную записать группу. Занятые и прошедшие варианты недоступны; перед сохранением хранилище повторно проверяет занятость.
- Отмена брони с подтверждением освобождает слот. Escape и крестик закрывают панель, фокус возвращается к исходному элементу.
- В навигации расписание, «Доп. оборудование» и ссылка на клиентский сайт.
- Плашка «Демо-концепт» оформлена как на клиентском сайте. Фокус полей нейтральный; счётчик занятых слотов и баннер после записи убраны.
- Плашка расположена по центру шапки. Свободные ячейки показывают только плюс, без цены при наведении.
- Выбор зала, времени, способа связи и фильтр залов используют общий компонент нестандартного списка с клавиатурной навигацией. Escape закрывает список, не закрывая форму. Имя или название группы можно указать и в админке, и на клиентском сайте.

Все новые записи создаются автоматически со статусом «Забронирована». Старые ожидающие заявки преобразуются в забронированные без потери данных; старые режимы совместимы при чтении, но ручное подтверждение больше не используется.

В карточке можно добавить выданное дополнительное оборудование, включая количество микрофонов и бесплатные первые два. Изменения сразу сохраняются; цена зала сохраняется, сумма оборудования пересчитывается. Перед кнопкой «Завершить репетицию» есть галочка «Оплачено», включённая по умолчанию. Это выбор для завершения: оплата сохраняется только после нажатия кнопки. Если снять галочку, запись завершится без оплаты; затем доступна отдельная отметка оплаты. После закрытия записи оборудование и сумма не редактируются.

Основная кнопка завершения и «Ещё» стоят в одном ряду. Меню «Ещё» содержит неявку и отмену; недоступные до начала репетиции действия в меню не показываются. Escape закрывает меню, сохраняя карточку открытой. Видимая подпись «ВРЕМЯ» над временной колонкой убрана.

Для завершённой записи доступно действие «Отменить завершение» с подтверждением. Отдельной отмены оплаты нет. При возврате в «Забронирована» галочка оплаты восстанавливает состояние записи: оплачена — включена, не оплачена — выключена. Значение сохраняется после перезагрузки. Неявка остаётся в расписании и отменяется действием «Отменить неявку». Сумма, оборудование и контакт сохраняются.

Отдельного обязательного начала репетиции нет. Подсказка «Сейчас» относится только к расписанию. Прошедшие неоплаченные записи автоматически не завершаются. Неявку можно отметить после начала слота. Отмена и неявка сохраняются в данных; отмена будущей брони освобождает время для новой записи. Расчёт и неявка недоступны до начала репетиции. Отдельные блоки «Требуют расчёта» и «Отмены и неявки» в расписании не показываются.

Панель администратора демонстрируется на компьютере. Самостоятельная отмена на клиентском сайте, настоящий вход клиента и ограничения автоматической записи в этот этап не входят. Настоящие платежи не проводятся.

## Клиентский сайт

Тёмная тема по согласованному концепту, лента дат на 14 дней, карточки залов с фотографиями и временем. Подробности открываются по фото или названию. В оборудовании переключатель «В зале / Дополнительно»; дополнительное оборудование выбирается на месте. После выбора времени форма показывает сводку и кнопку «Войти через Telegram». По нажатию сразу открывается форма с демо-аккаунтом «Демо-музыкант»; промежуточного тестового экрана нет. Общая пометка демо-концепта сохраняется. Настоящие переходы в Telegram и секреты не используются. Затем остаются имя или название группы и согласие с правилами отмены. Контакт берётся из демо-аккаунта. Вход сохраняется в браузере до 30 дней, поддерживает выход и синхронизацию вкладок. Брони автоматически подтверждаются и сразу видны в расписании; в деталях стоит «Вход: Telegram · демо». Правила открываются отдельно с возвратом к заполненной форме. Подтверждение записи показывает зал, дату, время и стоимость.

## Данные и структура

- `src/Site.tsx`, `src/client.css`, `src/Equipment.tsx` — клиентский интерфейс.
- `src/Admin.tsx`, `src/admin.css` — административное расписание и панель записи.
- `src/AdminDatePicker.tsx`, `src/admin-dates.ts` — календарь и проверка введённых дат.
- `src/AdminSelect.tsx` — выпадающие списки админки.
- `src/main.tsx` — маршруты.
- `src/domain.ts` — цены, даты в московском часовом поясе, статусы, аренда и календарь.
- `src/store.ts` — единое хранилище демонстрационных броней и режимов.
- `data/base.json` — сведения о залах, цены, оборудование, правила и контакты. Неподтверждённые данные не подменяются вымышленными.
- `public/photos/` — фотографии; у залов 3 и 6 предусмотрены заглушки.

Брони хранятся в localStorage под ключом `point-of-count-demo-v1`. Вкладки одного браузера на одном адресе синхронизируются через `storage`; localhost и 127.0.0.1 используют разные хранилища. Начальные записи генерируются по дате: около 46% слотов в будни и 57% в выходные.

Данные не синхронизируются между устройствами. Для реального запуска нужны серверная база, проверка прав администратора и атомарное занятие слота. Meta robots и `robots.txt` ограничивают индексацию, но не защищают доступ.

## Публикация

Основные исходники разрабатываются в `repo-seed`. `../sites/point-rehearsal-dark` — отдельная техническая копия для публикации в ChatGPT Sites, с собственным Git и тем же идентификатором в `.openai/hosting.json`. Перенос изменений выполняется при публикации, автоматической синхронизации папок нет.

Клиентский сайт: https://point-rehearsal-dark-boris.t8naxx.chatgpt.site/

Админка: https://point-rehearsal-dark-boris.t8naxx.chatgpt.site/admin

Для альтернативного размещения на Vercel: Root Directory `repo-seed`, Build Command `npm run build`, Output Directory `dist`; `vercel.json` содержит SPA rewrite.

## Проверка

- Сборка TypeScript / Vite и тесты логики цен, календаря, ручного ввода дат, статусов и хранилища.
- В браузере: переключение даты, просмотр брони, ручная запись, сохранение после перезагрузки, отмена и освобождение времени.
- Десктопная сетка всех семи залов; мобильная версия проверяется только для клиентского сайта.
- Снимки для локальной проверки не включены в репозиторий.


## Доп. оборудование
Раздел `/admin/equipment`: поиск, фильтр категорий, статичные заголовки групп, добавление и редактирование позиций. Переключатель «На сайте» управляет клиентским списком, скрытые позиции доступны администратору. Каталог сохраняется в браузере и синхронизируется между вкладками. Количества демонстрационные, автоматическое резервирование остатков не выполняется.
